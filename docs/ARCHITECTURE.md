# Архитектура

foxViewer состоит из трёх слоёв. Все они работают в одном content-скрипте и общаются через глобальный объект `FOXV` (`src/core/core.js`).

```
platforms/  ← знают, как устроен конкретный сайт (селекторы, отправка текста)
core/       ← общие утилиты и база для площадок
features/   ← знают, что делать, но не знают, на каком сайте работают
main.js     ← соединяет выбранную площадку и все фичи
```

## Площадка (адаптер)

Объект, который регистрируется в `FOXV.adapters`. Чаще всего его собирает `FOXV.defineAdapter(config)` из `src/core/adapter-base.js`.
Он отвечает на вопросы «где сообщения», «где поле ввода», «как отправить текст», «куда вставить кнопку». Полный список полей конфига описан в начале `adapter-base.js`.

Контракт (методы, которые вызывают фичи и `main.js`):

| Метод | Назначение |
|---|---|
| `match()` | подходит ли адаптер текущей странице |
| `ensureTrigger(onClick)` | вставить кнопку фичи в панель ввода, если её там ещё нет |
| `isTrigger(node)` | является ли узел нашей кнопкой |
| `getAnchorRect()` | положение панели ввода |
| `sendText(text)` | отправить сообщение в чат, `Promise<{ok, error?}>` |
| `messageNodes()` | все элементы с текстом сообщений |
| `messageOf(node)`, `messagesIn(node)` | поиск сообщений при изменениях DOM |
| `scroller()` | прокручиваемый список сообщений (необязательно) |

## Фича

Регистрируется в `FOXV.features`:

```js
FOXV.features.push({
  name: 'my-feature',
  init(adapter) {},                  // один раз при старте
  onTick(adapter) {},                // часто: на мутации DOM и по таймеру
  onMessages(adapter, nodes) {},     // новые/изменённые сообщения; nodes === null — просканировать всё
});
```

Чтобы добавить фичу:

1. создать `src/features/<имя>/index.js` с регистрацией;
2. добавить файлы в `js` (и `css`) нужных блоков `content_scripts` в `manifest.json`.

Ошибка в одной фиче не ломает остальные.

## Фон

`src/background/background.js` выполняет запросы, которые content-скрипту недоступны (кросс-доменные). Сообщения идут в формате `{ ns: 'foxv', type, ... }`.

## Фича `gifs`

- `picker.js` — окно поиска, живёт в Shadow DOM, чтобы стили сайта не мешали;
- `renderer.js` — превращает `/tenor <ID>` в картинку и удерживает чат прижатым к низу;
- `index.js` — регистрация фичи.
