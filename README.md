# 🦊 foxViewer

Браузерное расширение, которое улучшает чаты стримов. Работает без собственного сервера.

**Сейчас умеет:** GIF и стикеры в чате (через Tenor).
**Дальше:** другие возможности добавляются как независимые «фичи» (см. [архитектуру](docs/ARCHITECTURE.md)).

## Поддерживаемые площадки

| Площадка | Статус |
|---|---|
| YouTube (чат стрима) | работает |
| VK Видео Live | реализовано по DOM-дампу, нужна проверка в браузере |
| Twitch | планируется |
| RuTube | планируется |
| GoodGame | планируется |

Новую площадку можно добавить одним небольшим файлом — [как это сделать](docs/ADDING_PLATFORMS.md).

## Как это работает

Кнопка **GIF** появляется в панели ввода чата. Выбранная гифка отправляется в чат обычным текстовым сообщением вида

```
/tenor 27161697
```

У тех, у кого расширение установлено, такое сообщение превращается в картинку. Остальные видят обычный текст.
Ссылки на медиа расширение получает с публичного сайта tenor.com, ключи API не нужны.

## Стандартная установка

Скачиваем [**последний релиз**](https://github.com/Vadim0102/foxViewer/releases)

**Firefox** (временно, до перезапуска браузера): `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение…» → выбрать скачанный архив.

**Chrome / Edge:** `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное расширение» → выбрать скачанный архив.

Увы, на установку из магазина пока нет возможности. Пользуемся так.

## Установка из исходников

**Firefox** (временно, до перезапуска браузера): `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение…» → выбрать `manifest.json`.

**Chrome / Edge:** `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное расширение» → выбрать папку проекта.

С Node.js:

```bash
npm install
npm run start:firefox   # запуск в Firefox с автоперезагрузкой
npm run lint            # проверка manifest.json (web-ext)
npm run build           # сборка в web-ext-artifacts/
npm run check           # быстрая проверка без зависимостей
```

## Структура

```
manifest.json
src/
  core/         общее ядро: утилиты, реестры, база для адаптеров площадок
  platforms/    по одному файлу на площадку (youtube.js, vkvideo.js, _template.js)
  features/     возможности расширения (сейчас gifs/)
  background/   фоновый скрипт: запросы к tenor.com
  main.js       точка входа: выбирает площадку и запускает фичи
docs/
```

## Ограничения

- Tenor закрыл официальный API, поэтому используется разбор публичных страниц сайта. Если Tenor изменит вёрстку, поиск и получение гифок придётся поправить в `src/background/background.js`.
- Сайты периодически меняют вёрстку, и селекторы адаптеров могут устареть.
- Если у сайта строгий CSP, он может блокировать загрузку картинок с `media.tenor.com`.
- Не связано с Tenor, YouTube, VK, Twitch, RuTube и GoodGame.
